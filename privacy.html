Privacy Policy

Last updated: August 2026 · TradePro demo platform.

1. Summary

This demo collects nothing and sends nothing. There is no server, no analytics, no cookies for tracking, and no account database. Everything you do here stays inside your own web browser.

2. Data we store (locally)

The app uses your browser’s localStorage and sessionStorage:

  • tp_state_v1 — demo accounts (name, email, hashed password), cash balance, positions, orders, transactions and watchlist.
  • tp_session_v1 — which demo account is currently logged in.
  • tp_theme — light/dark preference.
  • Miscellaneous keys (tp_reset_email, cooldown timestamps) used by the auth flows.

Passwords are stored only as salted hashes produced by a lightweight client-side function. This is adequate for a sandboxed front-end demo but is not production-grade cryptography — never reuse a real password here.

3. Third parties

The site loads three static assets from public CDNs: the Inter font (Google Fonts), Font Awesome icons and the TradingView Lightweight Charts library. These requests are standard CDN fetches; they carry no personal information from this application. If you prefer zero external requests, use the site offline after first load where your browser caches allow.

4. Your rights & data removal

You have complete control: open your browser’s developer tools → Application → Local Storage and delete the keys above, or use Dashboard → Account settings → Reset demo environment. Since there is no backend, deletion is instant and total.
